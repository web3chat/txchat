# dtalk 项目

dtalk 是一个基于 Go 语言开发的分布式聊天系统，采用微服务架构设计，提供完整的即时通讯解决方案。

## 项目框架

dtalk 项目采用分层微服务架构，包含以下核心服务：

### 核心服务
- **gateway**: API网关服务，统一入口和路由管理
- **auth**: 认证授权服务，用户身份验证和权限管理
- **backend**: 后端业务服务，核心业务逻辑处理
- **group**: 群组服务，群组管理和群组功能
- **groupmanage**: 群组管理服务，群组数据库管理功能
- **call**: 音视频通话服务，实时音视频通信
- **record**: 消息记录服务，消息存储和检索
- **backup**: 备份服务，数据备份和恢复
- **discovery**: 服务发现，微服务注册与发现
- **oss**: 对象存储服务，文件上传和管理
- **offline-push**: 离线推送服务，消息推送通知

### 技术栈
- **编程语言**: Go 1.19+
- **Web框架**: Gin
- **数据库**: MySQL 8.0+, Redis 6.0+
- **消息队列**: Kafka
- **服务发现**: etcd
- **容器化**: Docker
- **API文档**: Swagger
- **构建工具**: Make

## 项目主要逻辑

### 1. 用户认证流程
用户通过认证服务进行身份验证，获得访问令牌，然后通过API网关访问各个微服务。

### 2. 消息处理流程
消息通过网关路由到相应的服务，经过业务逻辑处理后存储到数据库，同时触发推送通知。

### 3. 群组管理流程
群组创建、加入、退出等操作通过群组服务处理，群组信息通过群组管理服务进行数据库管理。

### 4. 音视频通话流程
音视频通话通过专门的call服务处理，支持实时音视频通信和信令交换。

## 项目功能

### 核心功能
- **用户管理**: 用户注册、登录、个人信息管理
- **好友系统**: 好友添加、删除、好友列表管理

### 管理功能
- **群组管理**: 群组信息查询、修改、统计
- **白名单管理**: 群组创建权限控制
- **数据备份**: 数据备份和恢复
- **系统监控**: 服务状态监控和性能分析

## 新增服务：群组管理服务 (groupmanage)

群组管理服务是 dtalk 项目中的新增微服务，专门负责群组数据库相关功能的管理。

### 主要功能
1. **群组信息管理**: 查询、修改群组信息（最大人数、状态、名称等）
2. **群组列表查询**: 支持分页查询、关键词搜索、状态筛选
3. **群组统计**: 提供群组总数、活跃群组、封禁群组等统计信息
4. **白名单管理**: 群组创建白名单的增删改查功能
5. **白名单统计**: 白名单总数、启用数量、禁用数量等统计信息

### 技术特点
- **RESTful API**: 提供完整的HTTP API接口
- **分层架构**: Handler-Service-DAO三层架构设计
- **数据模型**: 完整的数据库模型和业务模型定义
- **错误处理**: 统一的错误处理和响应格式
- **文档支持**: 自动生成Swagger API文档

### 服务地址
- 默认端口: 18020
- API文档: http://localhost:18020/swagger/index.html
- 服务路径: /api/v1/groupmanage/

### 快速开始
```bash
# 进入群组管理服务目录
cd service/groupmanage

# 构建服务
make build

# 运行服务
make run

# 开发模式运行
make dev
```

更多详细信息请参考 [群组管理服务文档](service/groupmanage/README.md)。
